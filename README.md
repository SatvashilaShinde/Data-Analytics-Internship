## About the Project
It covers basic concepts of Python, Pandas, SQL, Statistics, and Data Visualization using a student dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- MySQL

## Topics Covered

1. **Python:** Variables, data types, operators, loops, functions, lists, tuples, sets, dictionaries, and exception handling.
2. **Pandas:** Data loading, data cleaning, filtering, sorting, and grouping.
3. **SQL:** Create, Insert, Select, Where, Order By, Group By, Joins, Update, and Delete.
4. **Statistics:** Mean, Median, Mode, Variance, Standard Deviation, Percentile, and Correlation.
5. **Data Visualization:** Bar Chart, Line Chart, and Histogram.

## Dataset
The project uses a student dataset containing:
- Student ID
- Name
- Department
- Age
- Study Hours
- Marks
- Attendance

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required Python libraries:
   ```bash
   pip install pandas numpy matplotlib
   ```
4. Run any Python assessment file:
   ```bash
   python python_assessment.py
   ```
